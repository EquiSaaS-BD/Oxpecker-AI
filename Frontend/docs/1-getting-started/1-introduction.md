# Oxpecker AI

Welcome to **Oxpecker AI**, an enterprise-grade medical intelligence and healthcare platform engineered for Bangladesh and emerging digital healthcare systems.

Oxpecker AI bridges Patients, Doctors, Diagnostic Centers, Hospitals, and Chamber Assistants into a synchronized, secure cloud platform.

## Architecture Highlights

Oxpecker AI is built on a high-velocity fullstack architecture:
- **Frontend & Serverless Gateway:** Next.js 15 (App Router, React 19, Tailwind CSS v4) hosted on Vercel Edge.
- **Database & Authentication:** Supabase Managed PostgreSQL with Row-Level Security (RLS) and Supabase Auth.
- **AI Intelligence Gateway:** Multi-model triage engine supporting Google Gemini, OpenAI, and DeepSeek with automated emergency detection.
- **Continuous Availability:** Automated GitHub Actions keep-alive workflows ensuring 100% database availability on free cloud tiers.

## Key Platform Capabilities

- **Intelligent Patient Triage:** Multi-model symptom evaluation with visual action cards, specialist recommendations, and immediate emergency alerts.
- **Doctor Clinical Workstation:** Real-time prescription generator (Rx Studio), longitudinal patient medical histories, and chamber schedule configuration.
- **Assistant Queue Console:** Real-time clinic queue management, walk-in patient intake, and waiting-room TV display broadcasts.
- **Hospital Bed & ICU Telemetry:** Live bed tracking, admissions management, and department directories.
- **Supreme Administrative Control:** God-level oversight across all users, credentials, bookings, and database entries.
