══════════════════════════════════════
  🔍 HOW TO USE / SEARCH GUIDE
══════════════════════════════════════
  1. জেনেরিক নাম দিয়ে সার্চ:
     → generics.json-এ "name" ফিল্ড দিয়ে সার্চ করুন
     → ফার্মাকোলজি, ডোসেজ, সাইড ইফেক্ট সব পাবেন

  2. জেনেরিক নামে ব্র্যান্ড খুঁজুন:
     → medicines.json-এ "generic_name" ফিল্ড দিয়ে ফিল্টার করুন
     → একই জেনেরিকের সব ব্র্যান্ড, দাম, স্ট্রেংথ পাবেন

  3. কোম্পানির ওষুধ খুঁজুন:
     → medicines.json-এ "manufacturer" ফিল্ড দিয়ে ফিল্টার করুন

  4. রোগ অনুযায়ী ওষুধ খুঁজুন:
     → generics.json-এ "indication" ফিল্ড দিয়ে সার্চ করুন

  5. ওষুধের ধরন অনুযায়ী খুঁজুন:
     → medicines.json-এ "dosage_form" ফিল্ড দিয়ে ফিল্টার করুন
       (Tablet, Syrup, Injection, Capsule ইত্যাদি)
